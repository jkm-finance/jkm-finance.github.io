1. Before you start

  • Address: https://jkm-finance.github.io/csa/
  • Browser: use Edge (or Chrome) on your work PC, in a normal window. Do not use InPrivate / Incognito: data may be lost when the window closes.
  • Password: jkm for hotel work (preparer, reviewer, Hotel DOF); apac for Area / Regional DOF consolidation. Enter it once per browser tab.
  • Name: type your name in Your name on the start screen. It is recorded in the change history. Preparers must type the name exactly as the reviewer wrote it in the assignment (e.g. Irene Kim).
  • Language: switch with KO EN JA. Items are shown translated; click Show English original to see the original. Enter into AuditBoard based on the English original.
Where is my data stored? Everything you enter is stored only in the browser on your PC; nothing is sent to a server. Work moves between people as files (by email, Teams or OneDrive). That is why you should set an automatic backup folder.
Can hotels get mixed up? No. Every workspace has a unique ID. Two hotels with the same name are still separate workspaces, and a file from another hotel, another year or another service type (Full/Focus) is refused automatically.

3. Reviewer (Manager)

3-1. Create the workspace

  1. Password jkm → type Your name → New CSA (reviewer).
  2. Enter the hotel name, choose service type Full (240 items) or Focus (145 items), then Create.
  3. When the yellow notice appears, click Choose backup folder and pick a folder inside OneDrive (e.g. OneDrive › Finance › CSA 2026 Backup). See section 7.

3-2. Assign sections and send the assignment file

  1. On the Assign tab, enter preparer names for each section, separated by commas (e.g. Irene Kim, Brad Jeong). Hotels without an FSSC can assign FSSC-marked items to hotel staff.
  2. Save assignment.
  3. Under Send assignment file, click Download assignment file (one file for everyone) or For {name}, and send the file by email, Teams or OneDrive.
  4. Changing the assignment raises its version. Sending a new assignment file updates only the assignment; preparers keep what they entered.

3-3. Merge submissions

  1. Merge & finalize tab → drop all received submission files into Merge submissions at once.
  2. The Merge preview shows, per file, New · Changed · Same · Conflict · Refused (locked) · Outside assignment. A file from another hotel or a damaged file is refused on its own; the others are still processed.
  3. For conflicts (two people answered the same item differently, or a submission arrived after you changed the item), click Resolve conflicts and pick the version to keep for each item, or Keep master for all. Versions not chosen are kept in the history.
  4. Items outside the assignment are applied only if you tick them.
  5. Apply. A restore point is created automatically just before.

3-4. Review — approve and return

  • Submitted items appear on the Review queue tab. Open an item and click Approve or Return. A reason is required to return.
  • Use Approve all n with a result to approve many at once.
  • Add notes under Review comments (comments can be added, not deleted).
  • The reviewer can edit an approved item directly. It stays Approved; if the CSA was already finalized, finalization is cleared. Entered (locked) items must be unlocked first.

3-5. Send review results

Merge & finalize tab → Download review file → send it to preparers. Approvals, returns and comments go back to them; edits they made in the meantime are not overwritten.

3-6. Enter in AuditBoard and lock

  1. Enter approved items into Hilton AuditBoard. Copy for AuditBoard on the item screen copies the result, Response and evidence location to the clipboard (the format will be adjusted once the AuditBoard screen is confirmed).
  2. When an item is entered, click Mark entered in AuditBoard. The item is locked: nobody can edit it and later submissions for it are refused.
  3. To correct a locked item, use Unlock (reason required). A restore point is made first.

3-7. Finalize and issue the final result file

  1. When every item has a result and is Approved (or Entered), Finalize and issue final file on the Merge & finalize tab becomes available. If it is greyed out, the remaining items are listed below it.
  2. Send the …_FINAL_v1_….json file to the Hotel DOF and the Area / Regional DOF.
  3. Changing content after finalizing clears the finalization (a notice appears at the top). Finalizing again issues v2; recipients see the highest version by default. Marking items entered or unlocking alone does not clear finalization.

3-8. Report and Excel

  • DOF report tab: score, results by section, findings and remediation, items on hold. Print / Save as PDF → choose “Save as PDF” (A4 portrait). Before finalizing the report carries a “DRAFT — not final” mark.
  • Export all to Excel on the Merge & finalize tab: every item with result, text, preparer and latest comment.
  • Overview: progress ((Yes+No+N/A) ÷ all), score (Yes ÷ (Yes+No); N/A and Hold excluded), by section, by preparer and by status.

4. Preparer

4-1. First start

  1. Save the assignment file from your reviewer (…_ASSIGN_….json) on your PC.
  2. Open the address, password jkm → type Your name exactly as in the assignment.
  3. Open assignment file (preparer) → choose the file. If your name is not in the list, a window lets you pick it.
  4. Next time, click the hotel under My workspaces to continue.

4-2. Answering items

  • Open your section from the tabs at the top and pick an item on the left. Filters (risk, status, unanswered only …) narrow the list.
  • Result: Yes (control operating) · No (gap) · N/A (not applicable) · Hold (pending — still checking).
  • Response: what you checked and how. Evidence location: file path or where it is kept. Samples tested: samples checked (period, count …). Up to 5,000 characters each.
  • If the result is No, always fill in the Remediation plan (action, owner, due date).
  • Input is saved automatically (the save time shows at the top right). There is no save button.
  • Hover over a greyed-out button or field to see why it is disabled (e.g. “Item is locked”, “Not your assigned section”).

4-3. Submit sections

  1. Submit & receive tab → under Submit sections, tick the sections to submit (● = yours).
  2. Download submission file. Items without a result are left out; you are warned about No without a remediation plan and sections not assigned to you.
  3. The submission is complete only when you send the …_SUBMIT_….json file to your reviewer.
  4. You may submit sections separately, and resubmit items after changing them.

4-4. Receive review results and fix returned items

  1. Drop the review file (…_REVIEW_….json) or a new assignment file into Receive reviewer files on the Submit & receive tab.
  2. The Returned tab lists returned items with the reason. Fix and submit again.
  3. Your unsent entries are never overwritten. Such items show “Differs from the reviewer's copy”; submit them again when you are done.
  4. Approved items cannot be edited by preparers. Ask the reviewer to return the item if a change is needed.
Preparers can also set Choose backup folder on the Backup tab to be safe if the PC fails.

5. Hotel DOF

  1. Receive the final result file (…_FINAL_v1_….json) from the reviewer.
  2. Password jkm → Open final result (Hotel DOF) → choose the file.
  3. Report tab: score, results by section, findings and remediation, items on hold. Item details tab: result and Response for every item (read-only).
  4. Print / Save as PDF → “Save as PDF” makes an A4 PDF. Turn on Show English original too to print the original under the translation.
  5. Results you opened stay in this browser. Next time use View saved final results on the start screen. Open a v2 the same way; older versions remain selectable at the top.

Nothing can be changed here. Ask the reviewer if a correction is needed.

6. Area / Regional DOF

  1. Receive final result files from each hotel's reviewer.
  2. Sign in with password apac (consolidation mode).
  3. Drop several hotels' files into Load final result files. For each hotel only the highest version is counted; older versions are kept as history.
  4. Hotels: score, Key/HR/MR, No, Hold and AuditBoard entry rate per hotel. Click a hotel name to open its DOF report.
  5. Section heatmap: hotel × section scores (with Full and Focus mixed, sections Focus does not have are blank).
  6. All findings: every No item with its remediation across hotels; overdue due dates are marked ⚠.
  7. Export consolidated Excel: three sheets — hotel summary, heatmap, findings.

A file with the same version number but different content is flagged ⚠ — please check with that hotel's reviewer. Remove only removes a hotel from this consolidation view; the hotel's own data is not affected.

Changing PC / handing over to a new reviewer

  1. On the old PC, Download full backup (or use …_LATEST.json from the backup folder).
  2. On the new PC: password → name → Restore from full backup → choose the file. The same workspace (same ID) is restored, so existing preparers' submission files still merge.

Hide or delete a workspace

  • Hide from list (data kept): hides it from the start screen list only. You can show it again any time.
  • Delete workspace permanently: only after ① downloading a full backup and ② typing the hotel name exactly. Restore points on this PC are deleted too, so the downloaded backup is the only way back.
Clearing browsing data (cookies and site data) deletes the work stored on this PC. If a backup folder was set, use Restore from full backup to bring it back.
If the red notice “An unexpected error occurred, so autosave has stopped” appears, first click Download full backup in it, then reload. Saving is stopped on purpose so that a broken state is never written.
